# Скрытая работа через установленный FF Bridge

Сначала ping/capabilities, фактическая версия, desktop_mode=coexist и активные задания. Возможности этой версии перечислены в capabilities; поддержка одного приложения не означает поддержку всех. Сначала исследовать programmatic_plan и подходящие команды/API. При поручении помощнику приложения библиотека файлов не заменяет помощника.

Все изменения — durable_call с постоянным request_key. При потере ответа получить request_status того же ключа, проверить completed, nested response.ok, exit_code и внешний эффект. outcome_unknown не разрешает новый ключ для повтора изменения. Перед Send сохранить намерение и ID.

1. computer_use с args `{"command":"hidden_start","worker_integrity":"medium","webview_debug":true}` для панели WebView; обычные hidden приложения могут использовать owner без debug. Возвращается session_id. Medium не повышает права и не доказывает обычную учётную запись.
2. computer_use с args `{"command":"hidden_request","session_id":"<возвращённый ID>","timeout_s":40,"request":{"command":"launch_app","app":"excel","document_path":"<абсолютная существующая собственная .xlsx>"}}`. Поддержанные app из capabilities. Возвращается собственный HWND/PID.
3. Через hidden_request: uia_observe {hwnd,options:{max_items:256}}, выбрать точный name/actions, получить generation/ref. uia_act {hwnd,generation,ref,operation:invoke,postcondition:<явная проверка>}. Чтение после SIDECAR_TIMEOUT_RESTARTED можно ограниченно получить заново, с повторной проверкой HWND; мутацию не повторять после attempted=true. Если элемент исчез после Invoke, сначала прочитать новый результат.
4. panel.discover {hwnd} → panel_id. panel.inspect {hwnd,panel_id} → controls и document text. Только панель собственного живого дерева процессов; чужие HWND/panel_id, изменившееся рождение/URL отвергаются.
5. panel.type {hwnd,panel_id,action_args:{selector:{name,role},text,postcondition:{selector,state:{value:text}}}}. Выбрать единственное поле из наблюдения, не угадывать роль.
6. panel.invoke с точной единственной кнопкой и явной postcondition. Для Send: postcondition наблюдавшегося поля value="". После единственной отправки только читать panel.inspect до завершения ответа; panel.verify проверяет состояние без изменения. Ошибка после попытки эффекта требует проверки результата, не нового Send.
7. document.save {hwnd,document_path:<тот же путь>} сохраняет собственный Excel или Word через native COM, не редактирует содержимое. Проверяются PID/HWND/точный FullName. Excel требует единственную книгу. Word привязан к документу точного native Window: единственное окно этого документа должно иметь тот же HWND; остальные окна процесса не выбираются по индексу или ActiveDocument. После Save независимо прочитать сохранённый файл.
8. computer_use {command:hidden_close,session_id}. Затем проверить отсутствие собственных процессов по сохранённой принадлежности. Никогда не завершать приложения по общему имени или удалять чужие профили. Сохранить действие, ответ, независимую проверку, ошибку/восстановление и уборку.

hidden_request.timeout_s ограничен0..60s; это срок одного вызова, не всей задачи. Тайм-аут может означать неизвестный результат изменения. Физический ввод/смена активного окна не используются. Обычный рабочий стол доступен только в отдельно разрешённом dedicated режиме. Недоступный вход/MFA или неподдержанное приложение объяснить конкретно, не обходить Windows.

Доказательства задач и версии сохраняются отдельно; эта инструкция не объявляет установленную версию или все приложения готовыми.

Собственные текстовые редакторы семейства VS Code: через hidden_request `editor.launch {app:"cursor"|"vscode",document_path:<абсолютный существующий собственный UTF-8 файл>}`. Использовать timeout_s=60 для первого запуска. Мост создаёт отдельный профиль и локальное расширение только для своего экземпляра на скрытом рабочем столе. Входы и расширения владельца не переносятся. Для нестандартного размещения приложения допускается абсолютный executable с заранее проверенным expected_executable_sha256; произвольные параметры запуска не принимаются.

Затем `editor.observe {hwnd}` возвращает полный небольшой документ, version/text/file_sha256, generation/ref и личность собственного процесса расширения. Для порученной замены всего текста: `editor.replace_save {hwnd,generation,ref,expected_text,replacement_text}` с точными данными наблюдения. Лимит65536 символов, исходный файл не более262144 байт. Редактирование и Save выполняются через API самого редактора; физический ввод и clipboard не используются. ref расходуется перед отправкой. Чужое окно, изменившийся текст/версия/файл или закрытая программа отклоняются. После потери ответа не отправлять новую замену: проверить тот же durable request_key и сохранённый файл. При неизвестном исходе новый запрос изменения не разрешает автоматический повтор. Независимо прочитать файл и проверить содержание и saved_sha256; успешного Save недостаточно.

hidden_close завершает только собственную группу процессов и возвращает editor_profile_cleanup. Требовать removed=true и отсутствие точных путей. Перед удалением профиля сохраняются краткие записи исходов редактора без текста документа, с прежними пределами истории7 дней/2000 строк/8MiB; полный запрос/ответ хранится в основном durable journal. Ошибка уборки сохраняет путь для проверки принадлежности. Этот маршрут редактирования не выполняет задания помощнику Cursor и не означает скрытую поддержку всех Electron-приложений.

PowerPoint: app=powerpoint, существующий абсолютный собственный .pptx. Если уже запущен любой POWERPNT, новый скрытый запуск отклоняется с OWN_POWERPOINT_EXISTING_PROCESS_UNSUPPORTED: отдельный экземпляр не доказан. Не закрывать чужую программу ради проверки. Только свой PID/PPTFrameClass; целевой документ выбирается по native FullName, включая случаи окон восстановления. NativeOM от собственного дочернего mdiClass или paneClassDC привязан к единственному каноническому DocumentWindow и единственному окну этой презентации через COM identity, не через ActivePresentation и не через предположение о свойстве HWND.

document.read {hwnd,document_path} для PowerPoint возвращает slides[{slide_id,shapes:[{shape_id,name,text,auto_size}]}], максимум32 слайда/128 фигур на слайд/65536 символов. Для явно порученной замены простого текстового поля: document.replace {hwnd,document_path,slide_id,shape_id,shape_name,expected_text,replacement_text}. Использовать наблюдавшиеся IDs/name/text. Автоматически изменяющие размер поля отклоняются до эффекта (OWN_DOCUMENT_LAYOUT_UNSUPPORTED); требуется auto_size=0. Замена TextRange может изменить оформление отдельных фрагментов текста; для сложного оформления этот примитив не применять. После native Save проверить verified/saved, независимо разобрать PPTX, проверить целевой текст, соседние данные и расположение. document.save сохраняет ту же собственную презентацию без записи текста. Этот маршрут не является поручением помощнику PowerPoint.

Word запускается как app=word с существующим абсолютным собственным .docx; отдельный /n, только свой PID/OpusApp. При нескольких окнах выбирается документ с точно совпавшим native FullName. Через hidden_request document.read {hwnd,document_path} возвращает text. Для явно порученной замены всего простого текстового содержимого собственного документа: document.replace {hwnd,document_path,expected_text,replacement_text}. expected_text должен точно совпадать с прочитанным text; обе строки ограничены65536 символами. replacement_text включает обязательный конечный знак абзаца Word \r. Замена всего содержимого может сбросить его форматирование; для сохранения сложного оформления этот примитив не применять. Он заменяет текст в самом Word и сохраняет; требуются verified=true, отдельный разбор DOCX и проверка остальных данных. Панель Word может предлагать только чат: её открытие не доказывает редактирование документа помощником.
